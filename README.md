# ✨ BellaMake - Sistema de Controle de Estoque

📦 Sistema web desenvolvido para facilitar o controle de estoque, ajudando na organização de produtos, entradas e saídas de forma prática e eficiente.

## 🚀 Funcionalidades
- ✅ Cadastro e gerenciamento de itens
- ✅ Controle de estoque
- ✅ Interface moderna e responsiva
- ✅ Organização visual intuitiva
- ✅ Navegação simples e objetiva

## 🛠️ Tecnologias utilizadas
- ⚡ HTML
- 🎨 CSS
- 🧠 JavaScript
- ⚛️ React

## 📌 Objetivo
O projeto foi criado para demonstrar habilidades em desenvolvimento front-end, usabilidade e criação de interfaces funcionais para sistemas de gestão.

## 💻 Como executar
1. Clone o repositório  
2. Abra o projeto no navegador  
3. Acesse o arquivo `index.html` ou rode o projeto com o ambiente configurado
